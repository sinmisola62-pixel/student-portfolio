Building My Personal Portfolio

A digital space created to introduce who I am, showcase my growing skills and document my journey as a Computer Science student.

Project Preview

About the Project

This personal academic portfolio was developed to showcase my educational background, technical skills, interests and practical projects. It brings together different aspects of my academic and creative journey in one organised digital space.

The website includes multiple pages, an interactive academic planner, a contact form and multimedia elements. It also gave me an opportunity to apply the concepts I have been learning in web development.

Technologies and Tools

HTML CSS JavaScript Visual Studio Code Google Chrome

Key Features

  • Multi-page website with consistent navigation.
  • Personal profile and academic information.
  • Project showcase with individual project pages.
  • Interactive academic planner with task management.
  • Contact form with JavaScript validation.
  • Multimedia integration using video and audio.
  • Responsive layouts for different screen sizes.

My Role and Learning Experience

I worked on the design and development of this project, from structuring the pages with HTML to styling the interface with CSS and adding interactive features with JavaScript.

Through this experience, I gained practical knowledge of website structure, navigation, responsive design, DOM manipulation and problem-solving. I also learned the importance of testing, identifying errors and improving a project through continuous refinement.
